🛒 Projet E-commerce
Bienvenue sur mon projet de site E-commerce !
Ce projet est une plateforme de vente en ligne moderne, conçue pour offrir une expérience utilisateur fluide et intuitive. Elle permet aux utilisateurs de parcourir des produits, d’ajouter des articles à leur panier, de passer commande et de gérer leurs achats facilement.

✨ Fonctionnalités principales
  - Navigation par catégories et recherche de produits

  - Fiches produits détaillées (images, prix, description)

  - Système de panier dynamique

  - Gestion des commandes

  - Authentification et création de comptes utilisateurs

  - Interface d’administration pour gérer produits, commandes et utilisateurs

  - Paiement sécurisé (simulation)

🛠️ Technologies utilisées
Backend : Django

Frontend : HTML, CSS, JavaScript

Base de données :  MySQL, PostgreSQL

API de paiement :  PayPal

🚀 Objectif du projet
Ce projet a pour but de développer une solution complète de commerce électronique, évolutive et personnalisable, adaptée aussi bien aux petites boutiques qu'aux grandes plateformes de vente en ligne.
